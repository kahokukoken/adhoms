# 2〜5年目 Sequence Continuity Preflight / Implementation Plan

> 実装担当は superpowers:executing-plans を使用。現行正本と本Preflightから実装し、独立初読は表示本文だけを別担当へ渡す。

目的：人物・出来事・選択が前年度から積み重なる2〜5年目へ修正する。全文ユニークは補助検査であり、Sequence合格基準ではない。
Architecture：初年度を保持し、後年の通常FEED・会議・調査結果を年別の48月分データから選ぶ。状態は既存Memory/Relation/flags/最終結果を読み、人口シミュレーションや新たな施策選択を追加しない。
Tech：既存plain JavaScript、Playwright、standalone HTML。

## 1. 目的
最新ユーザー指示（2026-09-28）に従い、同じ人物が同じ問題の初回相談へ戻る構造を除く。週送り・月末直行の両方で、経験、関係、役割、施策の利益と負担、復旧が連続することを内部初読まで確認する。Human Acceptanceは未実施を維持。

6. 同じ人物の年齢・高校生等のプロフィールが固定。Year3/4の追加履歴投稿があっても周辺の通常会話が継続しない。

## 4. 現状実装と必要な年別化
`scripted-scenario.js` のmonths/current、authored.weeks/dialogue、ADHOMS_WEEKLY_SCENES、RESEARCH_BY_TOPICは季節12か月固定。年別なのはyearArcsのテーマ文と追加historyContextRowsだけ。
対象は後年48か月の通常24件/月、会議の相互応答、現在の観測に対する調査結果。年数接頭辞や同義語置換では足りない。初年度と固定済みの重要イベント・選択・結果計算は保持する。

|継続軸|保持する経験|2→3→4→5年目の変化|
|---|---|---|
|美咲/松本/西村/葵|初年度の乗れない便、送迎と仕事、乗務条件|連絡時刻の試行→待てる人へ負担が移る→代行・引継ぎを実地確認→豪雨前の集合/復旧の移動。葵は毎年同じ部活高校生へ戻さず進路と生活時刻を語る|
|北村/春香/斉藤|山際の帰路・給油・写真重複、冬の最後の区間|動けない理由→選択による利益/外側の負担→地区と仕事の協力条件→経路喪失後の生活再編|
|坂本/小林/寺西/村田|行事の丸印、受付と鍵、受取時刻、休息|昨年の誤解を直した上で別の困難→常連への偏り→役割の引継ぎ→休止/再開の条件。初回相談を再演しない|

## 5. 影響範囲・ファイル境界
- `ver1/ver1-continuity-year{2,3,4,5}.js`：年別の月packet（24投稿、会議、調査）。本文データのみ。
- `ver1/ver1-continuity.js`：年別選択、既存状態を読む本文resolver、プロフィール。新規シミュレーションなし。
- `scripted-scenario.js`：改稿観測へ固有IDを与えて後年packetを描画、会議の必要な途中経緯を要約に含め、調査を当年内容へ。
- `index.html`：読込順・年齢表示。既存保存スキーマは変更しない。
- tests/監査：構造・枝・経路・復旧・保存の実表示検証、全年表示ログ、独立初読記録。
- docsと生成dist：正本対応・5区分・固定版。過去固定HTMLのバイトは保持。
