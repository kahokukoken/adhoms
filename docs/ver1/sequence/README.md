# 後年の連続性を検証する手順

対象：実証2〜5年目。初年度の入口・密度・保存契約は別の既存回帰で保護する。

1. `npm run test:sequence` は同人物同文の年をまたぐ再演と、`internal-review.json` の内部読者判定を別々に検査する。判定はstandaloneのsourceDigestに結び付け、未読のビルド・既知の断絶はexit 1にする。全文の一意性だけでSequence PASSにしない。
2. `tests/ver1-sequence-continuity.spec.js` は実表示における選択・Memory・Relation・年齢・調査・月末経路・最終結果・保存の分岐を確認する。同義語の差分を人物の成長と認定しない。
3. `node scripts/export-ver1-reading.mjs weekly` と `... monthly` は冷起動から実ゲームのボタンで進み、表示順の読書資料を `test-results/reading/` へ出す。48月分に加えて比較用初年度を含み、8月の災害は通常FEEDの代わりに実イベントを読む。
4. 設計に参加していない別の初読担当に表示本文だけを渡し、理解した人物・関係・出来事・判断の変化と、つながらない箇所を報告してもらう。先に問題リストや期待する理解を渡さない。
5. 指摘は採否理由と修正後の前後確認を記録する。全文ユニークでも、同じ問題→同じ初回相談→同じ結論ならFAIL。日常や季節が戻っても履歴が状況を変えていれば継続。
6. 自動PASS、内部AI初読、Human Acceptanceを分ける。最後は未実施のまま、ユーザーへ全編再読は求めない。
