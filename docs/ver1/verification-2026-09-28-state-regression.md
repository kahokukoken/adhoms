## 再発防止と残件

- [固定Regression Contract](regression-contract.md)に6必須ケースと不変条件を明文化。CIは機能とSequenceを別ジョブで判定し、既知の反復をexpected failureやcontinue-on-errorで合格へ変えない。
- `node scripts/build-standalone.mjs --check`は古いソース／改変HTML／manifest不一致を拒否。既存の配布固定版8本は変更なし。
- 会議本文・人物・週次本文の新規創作は今回行っていない。後年の文章個別化と人物経過は[既知監査](verification-2026-09-27-later-years-audit.md)の制作側残件。Q-01／Q-03も未確定のまま。
- ソース修正と自動検査が通ったことをもって「修正完了」「Ver1完成」としない。PRはdraft、merge／正式公開なし。
- ユーザーへの全編再確認依頼はしない。この変更の比較が必要な場合に限り、起動冒頭→第2週→4月会議→5月再開が最小範囲。任意制作・終盤・保存の回帰確認は制作側で実施済み。
